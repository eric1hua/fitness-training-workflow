# 设备替换库(exercise-substitutions)

> 当目标器械被占 / 维修 / 不存在时,使用替代动作。
> **原则**:替换动作练同一肌群,生物力学接近,重量可参考原动作 × 换算系数。

---

## 7. 踝友好变体(踝 dorsiflexion 敏感时)

> **踝 dorsiflexion 压力排序**(从高到低):
> ❌ 深蹲 / 弓步 / 高脚位倒蹬 / 站姿提踵 / 步行下坡
> ⚠️ RDL / 低脚位倒蹬
> ✅ 坐姿腿屈伸 / 俯卧腿弯举 / 坐姿提踵 / 髋外展内收

### 踝友好版 5 类动作组合(7/18 验证)

1. **倒蹬(低脚位)** → 股四 + 臀
2. **RDL** → 后链 + 臀(中等踝压)
3. **坐姿腿屈伸** → 股四孤立
4. **俯卧腿弯举** → 腘绳孤立
5. **坐姿提踵** → 小腿(零踝压)

## 8. 临时加项(等机器期间)

> 当主训动作的设备被占,**不切换主题**,临时插入相邻肌群动作。

| 主训 | 设备被占 | 临时加项 | 加项肌群 | 备注 |
|---|---|---|---|---|
| 腿屈伸 | 被占 | 坐姿推胸 | 胸 | 7/18 验证 |
| 倒蹬 | 被占 | 高位下拉 | 背 | 拉日临时 |
| 卧推 | 被占 | 三头下压 | 臂 | 推日临时 |
| 引体 | 被占 | 二头弯举 | 臂 | 拉日临时 |

⚠️ **临时加项规则**:
- 不冲重(用轻重量 + 中等 RPE)
- 不超过 4 组
- 进"今日顶组汇总"备查
- 总容量预算上调(主体 + 临时)

## 9. 决策树

```
设备被占?
├─ 是 → 主题不变,临时加项(第 8 节)
│     ├─ 主训设备被占 → 加相邻肌群
│     └─ 主训可练 → 正常执行
└─ 否 → 正常执行
     ├─ 关节/肌肉异常 → 替换(第 1-7 节)
     ├─ RPE 异常 → 调整 ±2.5kg(progressive-overload.md)
     └─ 单动作 > 2x 计划 → 强制收尾
```

## 10. 重量换算(实现)

**实现在 `scripts/fitness_lib.py`,换算系数表是 `fitness_lib.SUBSTITUTIONS`。**
上面各节的表格是给人看的说明,代码只认 `SUBSTITUTIONS` —— 两边有出入以代码为准。

```python
from fitness_lib import find_substitutes, substitute_weight

find_substitutes("倒蹬 45°")
# → [{'sub': '哈克深蹲', 'coef': 0.7, ...}, {'sub': '单腿倒蹬', 'coef': 0.5, 'unilateral': True, ...}, ...]

substitute_weight(80, "倒蹬 45°", "哈克深蹲")
# → {'weight': 55.0, 'unilateral': False, 'bodyweight': False,
#    'note': '哈克深蹲:80 × 0.7 ≈ 55 kg —— 轨迹更稳,踝背屈压力低'}
```

几个约定:
- **单边动作**(`unilateral: True`)的系数指**单边重量**,note 里会标 `kg/单边`
- **自重动作**(`bodyweight: True`)返回 `weight=None`,不编一个数字出来
- **未收录的组合**明确返回「需人工判断」,不会拿一个默认系数糊弄
- 换算结果按 `round_to_plate()` 取整到可用配重片

> 旧版这里写的 `SUBSTITUTION_TABLE` 从来没有定义过,`coef` 还混用了
> `0.5` 和 `"0.5 / 单腿"` 两种类型,靠 `"/" in str(coef)` 判断 —— 跑不起来。
